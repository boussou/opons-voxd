నా మాతృభాష ఫ్రెంచ్, కానీ నా సాఫ్ట్‌వేర్ పనిలో ఎక్కువ భాగం — కమిట్ మెసేజ్‌లు, కోడ్ కామెంట్లు, GitHub issues, అంతర్జాతీయ బృందాలతో చాట్, డాక్యుమెంటేషన్ — ఇంగ్లీష్‌లో జరుగుతుంది. అనర్గళంగా ఇంగ్లీష్ టైప్ చేయడం కష్టం కాదు; నిజమైన అడ్డంకి ఏమిటంటే మెదడులోని మిగతా భాగం మాతృభాషలో పనిచేస్తున్నప్పుడు ఇంగ్లీష్‌లో *ఆలోచించడం*. మీరే అనువదించాల్సిన అవసరం లేకపోతే, డిక్టేషన్ ఈ అడ్డంకిని పూర్తిగా తొలగిస్తుంది.

## సెటప్

నేను opons-voxd ను రెండు స్వతంత్ర push-to-talk హాట్‌కీలతో నడుపుతాను:

- **`Ctrl+Alt+W` — సాధారణ డిక్టేషన్.** నొక్కి ఉంచుతాను, ఫ్రెంచ్‌లో మాట్లాడతాను, వదులుతాను, కర్సర్ వద్ద ఫ్రెంచ్ టెక్స్ట్ టైప్ అవుతుంది. నోట్స్ కోసం, ఫ్రెంచ్ సహోద్యోగులతో చాట్ కోసం, ఫ్రెంచ్‌లోనే ఉండాల్సిన ప్రతిదానికీ.
- **`Ctrl+Alt+K` — డిక్టేషన్-మరియు-అనువాదం.** అదే చర్య, కానీ నేను ఫ్రెంచ్ మాట్లాడతాను, కర్సర్ వద్ద *ఇంగ్లీష్* వస్తుంది. ఇంగ్లీష్ మాట్లాడే ప్రేక్షకుల కోసం ఉద్దేశించిన ప్రతిదానికీ: కమిట్ మెసేజ్‌లు, PR వివరణలు, కోడ్ కామెంట్లు, GitHub issues, ఇంగ్లీష్ చాట్ ఛానెల్స్.

అనువాదకంలోకి కాపీ-పేస్ట్ లేదు, సందర్భం మార్చడం లేదు, మళ్ళీ టైప్ చేయడం లేదు. నేను మాట్లాడతాను, నా కర్సర్ ఇప్పటికే ఉన్న చోటే ఇంగ్లీష్ కనిపిస్తుంది.

## రెండు హాట్‌కీలు ఎందుకు, ఒకటి ఎందుకు కాదు

అనువాదం ఆ పనికి నిజంగా శిక్షణ పొందిన మోడల్‌తోనే బాగా పనిచేస్తుంది. రోజువారీ ఫ్రెంచ్ హాట్‌కీ కోసం నేను `large-v3-turbo` వాడతాను ఎందుకంటే అది వేగంగా ఉంటుంది — కానీ దాని అనువాద నాణ్యత తక్కువ, ఎందుకంటే అది ట్రాన్స్‌క్రిప్షన్ వేగం కోసం ఆప్టిమైజ్ చేయబడింది, అనువాదం కోసం కాదు. అనువాద హాట్‌కీ బదులుగా సరిగ్గా అనువదించే రెండో మోడల్ (`medium`) ను లోడ్ చేస్తుంది. రెండు మోడళ్లు ఒకేసారి GPU మెమరీలో ఉంటాయి; కొన్ని GB కంటే ఎక్కువ ఖాళీ ఉన్న కార్డ్‌పై ఈ అదనపు ఖర్చు పెద్ద విషయం కాదు.

## ప్రయత్నించండి

ఇది opons-voxd యొక్క ప్రామాణిక కాన్ఫిగరేషన్ — ఎలాంటి fork లేదా patch అవసరం లేదు. `OPONS_VOXD_PTT_HOTKEY`, `OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, `OPONS_VOXD_TRANSLATE_MODEL`, `OPONS_VOXD_LANGUAGE` కోసం ప్రధాన README లోని [Configuration](../README.md#configuration) మరియు [Push-to-talk-and-translate hotkey](../README.md#push-to-talk-and-translate-hotkey) చూడండి.

మీరు రోజువారీగా ఇంగ్లీష్ కాకుండా వేరే భాష మాట్లాడుతూ, ఇంగ్లీష్‌లో పని చేస్తుంటే, ఇది బహుశా ఈ ప్రాజెక్ట్‌లో అత్యంత ఉపయోగకరమైన ఫీచర్.
