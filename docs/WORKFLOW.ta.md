என் தாய்மொழி பிரெஞ்சு, ஆனால் என் மென்பொருள் வேலையில் பெரும்பகுதி — commit செய்திகள், குறியீட்டு குறிப்புகள், GitHub issues, சர்வதேச குழுக்களுடன் அரட்டை, ஆவணப்படுத்தல் — ஆங்கிலத்தில் நடக்கிறது. சரளமாக ஆங்கிலம் தட்டச்சு செய்வது கடினமல்ல; மூளையின் மற்ற பகுதி தாய்மொழியில் இயங்கும்போது ஆங்கிலத்தில் *சிந்திப்பதே* உண்மையான தடை. நீங்களே மொழிபெயர்க்க வேண்டியதில்லை என்றால், டிக்டேஷன் இந்தத் தடையை முழுவதுமாக நீக்கிவிடும்.

## அமைப்பு

நான் opons-voxd-ஐ இரண்டு தனித்த push-to-talk ஹாட்கீகளுடன் இயக்குகிறேன்:

- **`Ctrl+Alt+W` — சாதாரண டிக்டேஷன்.** அழுத்திப் பிடிக்கிறேன், பிரெஞ்சில் பேசுகிறேன், விடுகிறேன், கர்சரில் பிரெஞ்சு உரை தட்டச்சு ஆகிறது. குறிப்புகள், பிரெஞ்சு பேசும் சகாக்களுடன் அரட்டை, பிரெஞ்சிலேயே இருக்க வேண்டிய அனைத்திற்கும்.
- **`Ctrl+Alt+K` — டிக்டேஷன்-மற்றும்-மொழிபெயர்ப்பு.** அதே செயல், ஆனால் நான் பிரெஞ்சில் பேசுகிறேன், கர்சரில் *ஆங்கிலம்* வெளிவருகிறது. ஆங்கிலம் பேசும் பார்வையாளர்களை நோக்கிய அனைத்திற்கும்: commit செய்திகள், PR விளக்கங்கள், குறியீட்டு குறிப்புகள், GitHub issues, ஆங்கில அரட்டை சேனல்கள்.

மொழிபெயர்ப்பானில் நகல்-ஒட்டு இல்லை, சூழல் மாற்றம் இல்லை, மீண்டும் தட்டச்சு செய்வது இல்லை. நான் பேசுகிறேன், என் கர்சர் ஏற்கெனவே இருக்கும் இடத்திலேயே ஆங்கிலம் தோன்றுகிறது.

## ஏன் இரண்டு ஹாட்கீகள், ஒன்று அல்ல

அந்தப் பணிக்காக உண்மையிலேயே பயிற்றுவிக்கப்பட்ட மாடலுடன் மட்டுமே மொழிபெயர்ப்பு நன்றாக வேலை செய்யும். அன்றாட பிரெஞ்சு ஹாட்கீக்கு நான் `large-v3-turbo`-ஐ பயன்படுத்துகிறேன், ஏனெனில் அது வேகமானது — ஆனால் அதன் மொழிபெயர்ப்புத் தரம் மோசமானது, ஏனெனில் அது படியெடுப்பு வேகத்திற்காக மேம்படுத்தப்பட்டது, மொழிபெயர்ப்பிற்காக அல்ல. மொழிபெயர்ப்பு ஹாட்கீ அதற்குப் பதிலாக சரியாக மொழிபெயர்க்கும் இரண்டாவது மாடலை (`medium`) ஏற்றுகிறது. இரண்டு மாடல்களும் ஒரே நேரத்தில் GPU நினைவகத்தில் இருக்கும்; சில GB-க்கு மேல் இடமுள்ள கார்டில் இந்தக் கூடுதல் செலவு பொருட்டல்ல.

## முயற்சி செய்யுங்கள்

இது opons-voxd-இன் நிலையான உள்ளமைவு — எந்த fork அல்லது patch தேவையில்லை. `OPONS_VOXD_PTT_HOTKEY`, `OPONS_VOXD_PTT_TRANSLATE_HOTKEY`, `OPONS_VOXD_TRANSLATE_MODEL`, `OPONS_VOXD_LANGUAGE` ஆகியவற்றுக்கு முதன்மை README-இல் உள்ள [Configuration](../README.md#configuration) மற்றும் [Push-to-talk-and-translate hotkey](../README.md#push-to-talk-and-translate-hotkey) ஆகியவற்றைப் பார்க்கவும்.

நீங்கள் அன்றாடம் ஆங்கிலம் அல்லாத மொழி பேசி, ஆங்கிலத்தில் பணிபுரிந்தால், இது இந்தத் திட்டத்தின் மிகவும் பயனுள்ள அம்சமாக இருக்கக்கூடும்.
